# Introduction-to-Java ☕
Welcome to my Introduction to Java repository. In this repository, I will show you all of my projects including lab activities and other self invented projects applying my fundamental knowledge in Java programming language.

## 🚀Key topics
* **Printing the output of the program:** Using System.out.print();, and System.out.println(); to print the output of the program.
* **Using sequences in formatting the output:** Applying various sequences, such as \s \n, and \t in formatting the output of the program.
* **Using variables and datatypes:** Applying the use of variables to store a value and datatype to define what type of value a variable can only contain.
* **Using an input stream for user input:** Applying the use of Scanner class to allow for user inputs in the program.
* **Using conditional statements:** Using if else statements to make logic and decisions in the program.
* **Using iterations in the program** Using loops like for loop, and while loop to repeat an action numerous times in the program.
* **Using arrays in the program:** Using arrays to store multiple values in the program.
* **Using exception handling in the program:** Using exception handling like try catch to safely handle certain common errors in the program.

## 🚀Projects
* **Console based Invoice:** This is a harcoded invoice program appliying the use of print statements, and various sequences to format the output.
* **Area and Perimeter of a Rectangular Garden Calculator:** This is a hardcoded area and perimeter calculator program applying the use of variables, and datatypes to store the given size to calculate.
* **Grocery Calculator:** This is an interactive grocery calculator program that asks the user for product prices and the program calculates it applying the use of Scanner class, and basic arithmetic operations.
* **Grocery Discount Calculator:** This is a conditional discount calculator program that asks the user for the total of his/her groceries then check on how many discount based on his/her total applying the use of if else conditional statement.
